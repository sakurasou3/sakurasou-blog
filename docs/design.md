# Design

## Goal

シンプルで読みやすい技術ブログを目指す。

装飾よりもコンテンツの読みやすさを優先する。

## Theme

- ライトモード・ダークモードに対応する
- シンプルな配色を採用する
- コードブロックは読みやすさを重視する

## UI Principles

- 本文を主役にする
- コードブロックの可読性を優先する
- 過度なアニメーションは利用しない
- 迷わないUIを目指す

## Layout

- 記事一覧
- 記事詳細
- タグ一覧

を基本構成とする。

## Responsive

- PC
- タブレット
- スマートフォン

で閲覧できることを前提とする。

## Accessibility

- コントラストを確保する
- キーボード操作を考慮する
- セマンティックなHTMLを利用する
